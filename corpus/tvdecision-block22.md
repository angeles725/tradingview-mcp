## 22.1 - The lead and why it was plausible `[INFER]`

`[INFER]` [Block 21] noted `aci_next_alpha` (`analysis/forecast.py`) was built and tested but never called
from the live cone path (`analyze.py`/`periodic.py`). The live conformal table is a STATIC snapshot,
regenerated by batch; it cannot react to a regime shift — like the 2026-08-11 gold selloff that broke gold's
band — until regenerated. ACI (Gibbs-Candes 2021) updates the miscoverage online per maturation, which
should widen a band that starts breaking. Plausible, principled, and NOT the static global multiplier
already rejected.

## 22.2 - What was wired `[CERT]`

`aci_adapted_level(records, model, band, gamma=0.05)` replays `aci_next_alpha` over a group's scored records
in made_at order and returns the adapted coverage level `1 - alpha_T`, clamped `[0.5, 0.999]`
(`analysis/forecast.py`) `[CERT]`. `conformalize_band(..., adaptive=True)` takes the split-conformal delta at
that adapted level and reports `aci_level` + `static_delta_frac`; `conformal_report(..., adaptive=...)`
threads it. analyze.py reads `delta_frac` unchanged, so a live cone would inherit the adaptation with no
change to the consumer. Tests `test_aci_adapted_level_widens_after_misses_tightens_after_hits`,
`test_conformalize_band_adaptive_reports_aci_level_and_widens_on_misses`.

## 22.3 - The in-sample view flattered it `[CERT-live]`

Regenerating the table with ACI adapted each symbol sensibly IN SAMPLE: DE30EUR (under-covering 0.87, the
+2.17% gap miss from [Block 21]) widened to `aci_level` 0.97 / delta +18.6 bps vs +2.7 static; the
over-covering GBP/USDJPY/CN50 tightened (`sources/probes/aci-walkforward-session-2026-08-11.md`)
`[CERT-live]`. Exactly the regime-aware behavior the lead promised — and exactly the trap [Block 20] warns
about: in-sample coverage is guaranteed by construction and cannot reveal over-fitting.

## 22.4 - The walk-forward rejected it `[CERT-live]`

Train 70% -> test 30% over pooled live + backfill, mean OOS cover90 across 10 symbol groups (target 0.90):
raw 0.937 (|err| 0.044) · static 0.917 (0.067) · **ACI 0.842 (0.129, worst)**
(`sources/probes/aci-walkforward-session-2026-08-11.md`) `[CERT-live]`. ACI over-tightened the over-covering
markets BELOW nominal out-of-sample (AUDUSD 0.86->0.62, SPX 0.93->0.75, USDJPY 0.96->0.79). `[INFER]` The
gamma-step tuned on the train regime over-corrects the test regime — the SAME failure class as the B20
50%-band over-fit.

## 22.5 - Decision and the standing lesson `[INFER]`

`[INFER]` Shipped OFF: `conformal_report(adaptive=False)` is the default and the static table stays live.
ACI machinery is kept for future work that would need a real online-coverage guarantee, not this naive
replay. The standing lesson, now three times over ([Block 20] 50%-band, the earlier static-multiplier
rejection, and this): on this data every ADAPTIVE or TUNED correction that flatters in-sample has failed
out-of-sample. The cones are already near-nominal (raw OOS 0.94); the honest surface remains the static
per-symbol correction plus realized-coverage reporting, not a cleverer knob. An improvement is only an
improvement once it survives the hold-out.
